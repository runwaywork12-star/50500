# 50500.shop — فروشگاه کفپوش چرمی گلدوزی اختصاصی خودرو

پروژهٔ کامل فروشگاه آنلاین 50500: فروشگاه ری‌اکتی (RTL، تم تیره/روشن)، پنل مدیریت جامع، و سرور واقعی Node.js + PostgreSQL برای استقرار محصول.

---

## ۱. راه‌اندازی سریع (نسخهٔ مرورگری)

```bash
npm install
npm run dev          # محیط توسعه
npm run build        # خروجی نهایی: dist/index.html (تک‌پرونده، بدون وابستگی خارجی)
```

خروجی `dist/index.html` یک فایل مستقل است: CSS، JS و همهٔ تصاویر و فونت‌های Shabnam داخل آن inline شده‌اند.
برای پیش‌نمایی: `npm run preview` یا کافی است فایل را در مرورگر باز کنید (مسیرهای HashRouter هستند: `/#/products`).

---

## ۲. پنل مدیریت

- آدرس: `/#/admin`
- **ورود پیش‌فرض:** رمز `50500admin` (ایمیل نمایشی فقط ظاهری است).
- رمز فقط به‌صورت **هش SHA-256** در `localStorage` ذخیره می‌شود؛ هیچ‌جا متن ساده نگهداری نمی‌شود.
- **محدودیت تلاش:** ۵ ورود ناموفق = قفل ۳۰ ثانیه‌ای (هم در حالت مرورگری و هم در سرور).
- **نشست مدیر:** بعد از ۱۲ ساعت منقضی می‌شود.
- تغییر رمز (چه از صفحهٔ ورود و چه از «تنظیمات») **همیشه نیازمند رمز فعلی** است.
- فراموشی رمز: اگر رمز فعلی را در دست ندارید، دادهٔ `localStorage` مرورگر پاک شود تا رمز پیش‌فرض دوباره فعال شود (در نسخهٔ سروری از `ADMIN_PASSWORD` در `.env` استفاده می‌شود).

ماژول‌ها: داشبورد، سفارش‌ها، محصولات، **تصاویر خودرو** (آپلود عکس واقعی هر برند/مدل)، مشتریان، همکاری در فروش، کدهای تخفیف، مالی، محتوای سایت، نظرات، کارکنان، تنظیمات، صفحات و SEO، کتابخانه تصاویر، درگاه‌های پرداخت، ایجنت‌های AI، استقرار و امنیت.

## ۳. پرداخت (درگاه‌ها)

- **زرین‌پال (v4 واقعی):** `payment.zarinpal.com/pg/v4/payment/request.json` + `verify.json` با `currency: IRT`.
  بازگشت بانک به `/#/pay/callback` می‌رود و پرداخت با `verify` واقعی تأیید می‌شود (کد 100/101).
  شبیه‌ساز پرداختِ بدون کسر مبلغ **حذف شده** است.
- **به پرداخت ملت:** فقط از سرور قابل فراخوانی است (رمز وب‌سرویس نباید وارد مرورگر شود)؛ در نسخهٔ مرورگری غیرفعال است و پیام مناسب نشان می‌دهد.
- درگاه‌های سداد/سپ/زیبال در این نسخه پیاده‌سازی نشده‌اند و هنگام انتخاب، صریحاً اعلام می‌کنند.

## ۴. نسخهٔ واقعی با سرور (PostgreSQL)

پوشهٔ `server/` شامل API کامل است: `helmet`، rate-limit، احراز هویت staff با scrypt + TOTP، آپلود تصویر با `sharp`، پرداخت، و مهاجرت دیتابیس.

```bash
cd server
npm install
# فایل .env را از deploy/.env.example بسازید (DATABASE_URL، ADMIN_PASSWORD، ADMIN_SECRET)
npm run migrate        # اجرای schema.sql
npm run start          # یا npm run dev برای watch
```

کلاینت به‌طور خودکار سرور را تشخیص می‌دهد (`/api/public/bootstrap`) و حالت محلی را کنار می‌زند؛ از آن لحظه:
ورود ادمین از `/api/admin/login` (با محدودیت تلاش سمت سرور) انجام می‌شود، تصاویر در PostgreSQL ذخیره می‌شوند و سفارش‌ها دیگر به مرورگر وابسته نیستند.

راهنمای کامل استقرار:
- **روی ابر لیارا (توصیه‌شده):** [`LIARA.fa.md`](./LIARA.fa.md) — اپ Docker + دیتابیس PostgreSQL + فضای ذخیره‌سازی ابری، با فایل آمادهٔ `liara.json`
- روی سرور خودتان (Docker + Nginx + TLS): [`DEPLOY.fa.md`](./DEPLOY.fa.md)
- هر دو از پنل ← «استقرار و امنیت» هم قابل دانلود هستند.

## ۵. امنیت — چه چیزی واقعی است و چه چیزی نیست

| لایه | وضعیت |
| --- | --- |
| رمز ادمین (حالت مرورگری) | هش SHA-256، بدون متن ساده، قفل تلاش، نشست ۱۲ساعته |
| رمز ادمین (حالت سرور) | `ADMIN_PASSWORD` در `.env` + rate-limit سمت سرور + TOTP اختیاری |
| ورود کارکنان | scrypt + هش، سمت سرور |
| چاپ فاکتور/برچسب | همهٔ ورودی‌های کاربر escape می‌شوند (بستن تزریق HTML) |
| پرداخت | تأیید واقعی زرین‌پال روی callback؛ بدون ثبت «پرداخت‌شده» دستی |
| رمز وب‌سرویس بانک | هرگز به مرورگر نمی‌رود |
| XSS در گرافیک SVG | ورودی نام خودرو فقط در regex استفاده می‌شود، در SVG درج نمی‌شود |

**محدودیت صادقانه:** در حالت مرورگریِ خالص (بدون سرور)، داده‌ها و رمز در `localStorage` همان مرورگر است و هر کسی به مرورگر دسترسی داشته باشد می‌تواند آن را بخواند. برای محصول واقعی، استقرار بخش ۴ (سرور) الزامی است؛ تا آن زمان پنل را روی دستگاه خودتان نگه دارید و از `npm run preview` استفاده کنید نه اشتراک‌گذاری عمومی.

## ۶. سرعت

- **تک‌پروندهٔ ۴.۱MB** با gzip ≈ 2.57MB (همهٔ تصاویر و فونت‌ها inline — الزام هاست تک‌پرونده).
- FCP ≈ 760ms و DOMContentLoaded ≈ 170ms در تست مرورگر واقعی.
- `loading="lazy"` + `decoding="async"` روی همهٔ تصاویر پایین‌صفحه؛ `fetchPriority="high"` برای تصویر LCP هیرو.
- `content-visibility: auto` روی بخش‌های پایین‌صفحه (سوالات، نظرات، فوتر) برای اسکرول روان.
- فونت Shabnam با `font-display: swap` و زیرمجموعهٔ مجزا برای ارقام لاتین.
